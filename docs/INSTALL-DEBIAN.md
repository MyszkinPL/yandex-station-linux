# Debian на Яндекс Станции 1

Чистый Debian 13 (trixie) с нашим ядром Linux 7.3 на первой Яндекс Станции (YNDX-0001).
Ставится одним файлом из Android самой Станции, без ПК, без разборки и без пересборки:
всё уже собрано и лежит в [выпусках](https://github.com/MyszkinPL/yandex-station-linux/releases).
Android с Алисой остаётся на месте, к нему можно вернуться в любой момент и удалить Debian полностью.

## Что получится

- Debian 13 arm64: `apt`, SSH (dropbear), runit для своих служб, chrony, ALSA.
- Ядро 7.3 под Станцию: 4 ядра с DVFS 480–1152 МГц, Wi-Fi, Bluetooth, оба усилителя,
  микрофоны, кнопки, сторожевой таймер.
- Wi-Fi настраивать не нужно: Debian сам берёт сети, сохранённые в Android.
- Всё, что вы меняете в Debian (пакеты, настройки), хранится на флешке и переживает перезагрузку.

Чего нет: Алисы и приложения Яндекса в Debian (это Android). Голосовой помощник, музыка и
прочее — что поставите сами.

## Что нужно

- Яндекс Станция 1 (YNDX-0001), подключённая к Wi-Fi через приложение Яндекса.
- Оболочка root в Android Станции **с полными правами** (SSH под root, `adb root` — любым
  способом). Установщик сам проверит, хватает ли прав.
- Свободное место: 400 МБ в `/cache` и 150 МБ в `/data`. Если в `/cache` лежит скачанное
  обновление Android (`update_*.zip`, ~600 МБ), установщик подскажет, как его удалить.

## Установка

В оболочке root на Станции:

```sh
cd /data/local/tmp
curl -kfLo station-debian.run https://github.com/MyszkinPL/yandex-station-linux/releases/latest/download/station-debian.run
sh station-debian.run
```

(`-k`: в Android 6 нет хранилища сертификатов, которое понимает его curl. Всё, что установщик
скачивает дальше, он сверяет по sha256, зашитым в него самого. Хотите проверить и сам
`station-debian.run` — скачайте его на ПК и сравните с `SHA256SUMS` того же выпуска.)

Установщик спросит:

1. **Что запускать при включении**: Debian (по умолчанию), Android с Алисой, как сейчас,
   а Debian — по команде, или **Debian сразу** — быструю загрузку (ниже; предлагается, только
   если загрузчик Станции тот, на котором она проверена).
2. **Вход по SSH**: вставьте свой открытый ключ (`ssh-ed25519 ...`) или нажмите Enter —
   тогда будет пароль root, он покажется **один раз** в конце.
3. **Ещё одна сеть Wi-Fi** (необязательно).
4. **Часовой пояс** (по умолчанию `Europe/Moscow`).

Дальше он сам: проверит Станцию, скачает и сверит файлы, сохранит копию стокового recovery,
распакует Debian, запишет ядро в recovery с проверкой обратным чтением, научит Android
передавать Станцию Debian и перезагрузит её. Каждый шаг печатается с `[ok]`; на любой ошибке
установщик останавливается и пишет, что делать. Запуск ещё раз продолжает с того места.

Без вопросов, одной командой:

```sh
sh station-debian.run install --yes --key "ssh-ed25519 AAAA... me@pc" --tz Asia/Yekaterinburg
```

Без интернета на Станции: положите файлы выпуска в папку на Станции и добавьте `--from <папка>`.
Только проверить, ничего не меняя: `sh station-debian.run check`; скачать и сверить всё заранее:
`sh station-debian.run download`.

## Первый вход

Через минуту после перезагрузки:

```sh
ssh root@<адрес Станции>
```

Адрес обычно тот же, что был у Станции в Android (его видно в роутере). Дальше обычный Debian:

```sh
apt update && apt install htop
station-wifi add "Моя сеть" "пароль"     # ещё сеть Wi-Fi; list, forget — тоже
aplay -D station_speakers звук.wav        # звук через оба усилителя
```

Свои службы — как обычно в runit: каталог со скриптом `run` в `/etc/service/`.

## Как Станция загружается

**Обычно** при включении сначала стартует Android (так устроен загрузчик Яндекса, его мы не
трогаем). Когда он загрузился и две минуты держит Wi-Fi, он передаёт Станцию Debian:
перезагрузка, и через ~30 с Debian в сети. От включения до Debian — около 3–4 минут.

Если Debian не смог подняться (нет Wi-Fi-модуля, нет системы), он сам возвращает Станцию в
Android и отмечает почему; Android после этого остаётся и Debian не запускает, пока вы не
скажете. Петли перезагрузок не бывает.

**Быстрая загрузка** (`--mode direct`, пункт 3 в меню): ядро Debian ставится в раздел boot, и
Станция включается сразу в Debian — SSH через ~15 с. Android переезжает в recovery и остаётся
доступен: кнопка Алисы 10 с или `station-android` в Debian — и Станция в Android; обычная
перезагрузка Android — снова Debian. Если Debian трижды подряд не поднялся (или ядро сломано),
загрузчик Станции сам уходит в Android: это делает первый код образа ещё до ядра. Установщик
предлагает быструю загрузку только на загрузчике (boot0, U-Boot), на котором она проверена, и
сохраняет прежний образ boot; `uninstall` возвращает его на место.

## Вернуться в Android, переключить, удалить

Из Debian:

| | |
|---|---|
| `station-android` | в Android и остаться там |
| `station-reboot` | перезагрузка (Станция вернётся в Debian) |
| кнопка Алисы, держать 10 с | в Android и остаться там (работает, даже если сеть пропала) |

Из Android (оболочка root, тот же файл):

| | |
|---|---|
| `sh station-debian.run status` | что в recovery и как прошла последняя загрузка Debian |
| `sh station-debian.run enter` | загрузить Debian сейчас |
| `sh station-debian.run stay` / `unstay` | при включении — Android / снова Debian (не для быстрой загрузки) |
| `sh station-debian.run log` | полный журнал последней загрузки Debian |
| `sh station-debian.run access` | новый пароль root или ещё один ключ для Debian (если старый потерян) |
| `sh station-debian.run update` | новое ядро из выпуска этого установщика (Debian остаётся как есть) |
| `sh station-debian.run uninstall` | удалить всё: Станция как была |

Debian обновляется сам по себе, через `apt`. Новый выпуск ядра — новый `station-debian.run` и
`update`.

## Забыли пароль или потеряли ключ

Ничего страшного: доступ выдаётся заново из Android, Debian для этого не нужен.

1. Удерживайте кнопку Алисы 10 секунд — Станция уйдёт в Android и останется там.
2. В оболочке root Android: `sh /data/local/tmp/station-debian.run access` — Enter даст новый
   пароль (покажется на экране), или вставьте новый открытый ключ.
3. `sh /data/local/tmp/station-debian.run enter` — Debian загрузится уже с новым доступом.

Пароль и ключи, которые вы меняете в самом Debian (`passwd`, `~/.ssh/authorized_keys`),
сохраняются: установщик их не перетирает, пока вы сами не попросите `access`.

## Что установщик меняет на Станции

- раздел **recovery**: туда пишется наше ядро (стоковый сохраняется в
  `/data/local/station/backup/`, при удалении возвращается; если копии нет, Android
  собирает свой из раздела boot сам);
- **`/system/etc/rc.local`**: одна строка, запускающая передачу в Debian (прежний файл —
  `rc.local.before-station`); `/system/recovery-from-boot.p` переименовывается, чтобы Android
  не затёр наше ядро стоковым;
- **`/cache/station/`**: сам Debian и всё, что в нём меняется;
- **`/data/local/station/`**: установщик, скачанные файлы, журнал `install.log`;
- последние 4 МБ раздела **misc** (их Android не использует): журнал загрузки Debian;
- при быстрой загрузке ещё **boot**: туда ядро Debian, а образ Android — в recovery (прежний
  boot сохраняется в `/data/local/station/backup/boot-android.img`, при удалении возвращается).

Загрузчики (boot0, U-Boot) и данные Android не трогаются; раздел boot — только при быстрой загрузке.

## Если что-то пошло не так

- Установщик остановился — прочитайте, что он написал под `[x]`, и запустите снова.
- Debian не появился в сети за 5 минут — обычно Станция к этому времени уже сама вернулась
  в Android. Если нет (не отвечает совсем) — выдерните её из розетки на 10 секунд:
  включится Android и останется в нём. Там `sh station-debian.run status` скажет, на чём
  Debian остановился, `log` — подробно.

С журналом (`/data/local/station/install.log` и вывод `status`) приходите в
[issues](https://github.com/MyszkinPL/yandex-station-linux/issues).

## Ядро отдельно

В каждом выпуске есть `kernel-<версия>.tar.gz`: `Image`, DTB, модули, `config` — для своих
сборок. `recovery-station.img` — готовый образ для раздела recovery (shim + DTB + ядро +
initramfs), `recovery-station-fixed.img` — то же с постоянной частотой процессора, для
проверки, если с DVFS что-то не так. Собрать всё самому — в [README](../README.md#сборка).
