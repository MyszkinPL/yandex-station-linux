# Установщик Debian из своего приложения

Для тех, кто запускает `station-debian.run` из своей программы (приложение для Станции, бот,
скрипт на ПК), а не руками в терминале. Человеческий гайд — [INSTALL-DEBIAN.md](INSTALL-DEBIAN.md).

## Где взять

Последний выпуск, всегда по одному адресу:

```
https://github.com/MyszkinPL/yandex-station-linux/releases/latest/download/station-debian.run
https://github.com/MyszkinPL/yandex-station-linux/releases/latest/download/SHA256SUMS
```

Или одной командой для человека — `install.sh` (скачивает установщик своего выпуска, проверяет,
что тот скачался целиком, и запускает с терминалом): `curl -kfsSL .../latest/download/install.sh | sh`,
флаги — после `sh -s --`. Приложению удобнее скачивать сам `.run`, как ниже.

Конкретный выпуск — `releases/download/debian-vN/...`. Всё, что установщик скачивает сам, он
сверяет с sha256, зашитыми в него; сам `station-debian.run` проверяйте по `SHA256SUMS` того же
выпуска (на ПК или в своём приложении: curl Android 6 не проверяет сертификаты, `-k`).

## Как запускать

На Станции, в Android, **под root с полными правами** (как у SSH под root или `adb root`):

```sh
cd /data/local/tmp
curl -kfLo station-debian.run https://github.com/MyszkinPL/yandex-station-linux/releases/latest/download/station-debian.run
sh station-debian.run <команда> --machine [флаги]
```

- `--machine`: на **stdout** — только строки `@...` (ниже), весь человеческий текст — на
  **stderr** (его можно показывать как есть, он по-русски). Вопросов в этом режиме нет,
  всё задаётся флагами.
- `install` и `enter` в конце **перезагружают Станцию**: SSH-сессия оборвётся. Запускайте
  отвязанно и читайте вывод из файла, например:
  `setsid sh station-debian.run install --machine ... > /data/local/tmp/inst.out 2> /data/local/tmp/inst.log < /dev/null &`
- Повторный запуск безопасен: сделанное и проверенное он пропускает, продолжает с места сбоя.
- Два установщика одновременно не запускайте.

## Команды

| команда | что делает | перезагружает |
|---|---|---|
| `version` | версия выпуска (`@version debian-vN`) | нет |
| `check` | проверяет Станцию, ничего не меняет; код 2 — есть что решить до установки (`@blocked`) | нет |
| `download` | `check` + скачивает и сверяет файлы выпуска; ничего не меняет | нет |
| `install` | ставит (см. флаги) | да, в Debian (если `--mode android` — нет) |
| `status` | что стоит и как прошла последняя загрузка Debian (`@status`) | нет |
| `enter` | загрузить Debian сейчас | да |
| `access` | новый пароль root или ещё ключ (потерянный доступ) | нет |
| `update` | новое ядро из этого выпуска; Debian и его данные не трогает | да |
| `stay` / `unstay` | при включении Android / снова Debian (не для `direct`) | нет |
| `log` | полный журнал последней загрузки Debian (текст) | нет |
| `uninstall` | убирает всё, Станция как была (с `--machine`/`--yes` — без вопроса) | нет |

Флаги `install`:

| флаг | |
|---|---|
| `--mode debian` | (по умолчанию) Android включается первым и через ~2 мин передаёт Станцию Debian |
| `--mode android` | Android как был; Debian — по `enter` |
| `--mode direct` | быстрая загрузка: Debian сразу из boot (~15 с), Android — в recovery. Только если `@status ... direct_ok=yes` (загрузчик тот, на котором это проверено), иначе код 10 |
| `--key "ssh-ed25519 ..."` | ключ для входа root по SSH |
| `--password` | сгенерировать пароль root (придёт в `@password`). Без ключа и без пароля — пароль |
| `--wifi "<имя>" "<пароль>"` | ещё одна сеть (сети из Android Debian берёт сам) |
| `--tz Europe/Moscow` | часовой пояс |
| `--from <папка>` | файлы выпуска уже лежат на Станции (без интернета) |

## Строки `@...`

Одна строка — одно событие, поля через пробел, последнее поле — текст до конца строки.

| строка | когда |
|---|---|
| `@start <команда> <версия>` | в начале |
| `@step <текст>` | начат этап |
| `@ok <текст>` | шаг сделан и проверен |
| `@warn <текст>` | замечание, работа идёт дальше |
| `@download <файл>` / `@unpack <файл>` / `@write recovery\|boot` | долгие шаги (до минуты-двух) |
| `@password <пароль>` | сгенерированный пароль root; больше нигде не показывается |
| `@blocked <причины>` | `check`: что мешает установке |
| `@status key=value ...` | `status`: `installed=yes\|no mode=debian\|android\|direct\|none recovery=debian\|android\|stock\|other last_boot=ok\|early\|to-android\|stay\|handoff\|none version=... rootfs=... direct_ok=yes\|no` |
| `@done <команда> [mode=...]` | команда закончилась успешно |
| `@reboot direct\|recovery` | сейчас перезагрузится |
| `@problem <код> <что \| что делать>` | проверка нашла проблему; все проблемы идут подряд, потом `@fail` (или `@blocked` у `check`) |
| `@fail <код> <что \| что делать>` | ошибка; затем выход с этим кодом |

## Коды выхода

| код | |
|---|---|
| 0 | готово |
| 1 | ошибка (смотрите `@fail` и журнал) |
| 2 | `check`: есть что решить до установки; `install`: на месте Debian другая система |
| 3 | это не Станция 1, не её Android или не та разметка |
| 4 | нет root или прав на запись разделов |
| 5 | нет сети или не скачалось (с проверкой sha256) |
| 6 | мало места (`/cache` 400 МБ, `/data` 150 МБ) |
| 7 | запись в раздел не прошла обратное чтение (установщик уже вернул прежнее, если мог; «НЕ ПЕРЕЗАГРУЖАЙТЕ» в тексте — не перезагружать и повторить) |
| 8 | Debian не установлен (для `enter`, `access`, `update`) |
| 9 | отменено |
| 10 | `--mode direct` на непроверенном загрузчике |
| 11 | неверные флаги |

## Обычный сценарий

1. `check --machine` → код 0, или показать человеку все `@problem` (каждая — что не так и что сделать).
2. `install --machine --mode debian --key "<ключ пользователя>"` отвязанно; ждать `@reboot`.
3. Ждать SSH Станции (порт 22): Debian ответит через ~3 мин (`debian`) или ~15 с (`direct`).
   Не ответил за 5 мин — Станция сама вернулась в Android: `status --machine` расскажет почему.
4. Пользователь потерял пароль: из Android `access --machine` → `@password`, потом `enter`.

В Android из Debian: кнопка Алисы 10 с или `station-android`; обратно — `enter` (или обычная
перезагрузка Android при `direct`). Журнал установщика — `/data/local/station/install.log`.
