# Mali-400 MP2 (utgard)

Драйвер ядра для GPU Станции, нужный родному Android (`libGLES_mali` r6p0). Lima из mainline
с вендорским blob не работает: у них разный интерфейс ядра, поэтому берём драйвер самого ARM.

- исходник: ARM `DX910-SW-99002-r10p0-00rel0` (последний выпуск utgard, GPL-2.0),
  скачивается при сборке с developer.arm.com и сверяется по `source.sha256`;
- `patches/bootlin/`: серия Bootlin sunxi-mali (платформа sunxi, сборка до 5.10),
  без 0013 (r10p0 уже на timer_setup); в 0022 убраны CRLF, в r10p0 файлы с LF;
- `patches/0100-*`: наш перенос на современные ядра (7.x);
- `patches/0102-*`: состояние fence через `dma_fence_get_status()` (`ops->signaled` необязателен).

- `patches/0101-*`: интерфейс r6p0 (API 800) рядом с родным API 900, для вендорского
  `libGLES_mali` r6p0-01rel0. Отличия описаны в `common/mali_uk_r6p0.h` (после патчей):
  раскладка заданий GP и выделения памяти, а в r6p0 кучу PLBU растит ядро. Раскладка
  проверена по константам ioctl в коде самой вендорской библиотеки.

Проверка на Станции: `perl tests/api800.pl` после `insmod mali.ko` (рукопожатия 800/900,
выделение памяти r6p0, каждая версия принимает только свои ioctl).
